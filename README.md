# DevOps Lab

## Overview
This repository contains hands-on DevOps lab exercises and projects for learning modern DevOps practices and tools.

## Topics Covered
- Containerization (Docker)
- Orchestration (Kubernetes)
- Infrastructure as Code (IaC)
- CI/CD Pipelines
- Configuration Management
- Monitoring and Logging
- Cloud Deployment

## Prerequisites
- Linux/Unix basics
- Basic programming knowledge
- Familiarity with command-line tools
- Docker and container concepts

## Getting Started
1. Clone the repository
2. Navigate to the desired lab directory
3. Follow the instructions in each lab's README

## Requirements
- Docker
- Kubernetes (kubectl)
- Git
- Python 3.x or Node.js (depending on labs)

## Lab Structure

devops-lab/
